brain

Private. Nothing on this page comes from the public site — it reads and writes jberusch/brain, which is a private repo, using a token you paste in and that stays in this browser.

One-time setup
  1. Make a fine-grained token: github.com/settings/personal-access-tokens/new
  2. Repository access → Only select repositories → pick brain and jberusch.github.io
  3. Permissions → Repository → Contents: Read and write. Nothing else.
  4. Set an expiry you're happy with, generate, paste below.

Fine-grained, not classic: a classic repo token would hand this page every repo you can touch. This one reaches two.
